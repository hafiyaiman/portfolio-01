Your Maps3D map

This zip contains:
- your exported 3D model file
- a .maps3d.json file with the exact settings used to build this map

To edit or re-download this map:
1. Go to https://maps3d.io and open the 3D map editor
2. Click "Open" and choose the .maps3d.json file from this zip

Your map opens exactly as you left it, so you can tweak the settings and export again. If you purchased this map, opening the file also restores your download.

Size: 220 × 207 mm
Scale: 1:9642
Original size: 2.1 km × 2 km
Coordinates: georeference.json in this zip maps positions on the model back to real-world coordinates.
